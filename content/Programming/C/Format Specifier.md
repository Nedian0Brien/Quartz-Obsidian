
C언어의 형식 지시자
1. 정수(integer) 형식 지시자
	1. %d : 정수를 10진수로 출력
	2. %x : 정수를 16진수로 출력
	3. %o : 정수를 8진수로 출력
	4. %u : 부호 없는 정수를 10진수로 출력
2. 부동 소수점(float) 숫자 형식 지시자
	1. %f : 부동 소수점 숫자(float)를 출력
	2. %e / %E : 부동 소수점 숫자를 지수 표기법(과학적 표기법)으로 출력
	3. %g / %G : 부동 소수점 숫자를 지수 표현 / 고정 소수점 표현 중 가장 간결한 형식으로 표현
3. 문자 형식 지시자
	1. %c : 문자를 출력
	2. %s : 문자열을 출력
4. 기타 형식 지시자
	1. %p : 포인터 주소를 출력
	2. %% : '%' 기호 자체를 출력
