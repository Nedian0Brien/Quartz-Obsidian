# variable-length arguments

파이썬 함수에서 `*args`와 `**kwargs`는 가변 인자(variable-length arguments)를 처리하기 위한 문법
- `*args`는 <mark style="background: #FFB86CA6;">위치 기반 인자(positional arguments)</mark>를 가변 개수만큼 받는 구조
- `**kwargs`는 <mark style="background: #D2B3FFA6;">키워드 기반 인자(keyword arguments)</mark>를 가변 개수만큼 받는 구조

즉, 이는 **호출 시 몇 개의 인자가 들어올지 미리 알 수 없는 상황을 처리하는 기능**

### `*args`의 동작 방식

함수에 전달된 위치 인자들을 하나의 튜플(Tuple)로 받아들임
```cpp
def func(*args):
    print(args)

func(1, 2, 3)
# 출력: (1, 2, 3)
```

즉, 다음과 같은 상황에서 유용
- 전달 인자의 수가 가변적일 때
- 인자의 개수를 코드 작성 시점에 알 수 없을 때
- 리스트 또는 튜플 하나를 여러 개의 인자로 나누어 전달하고 싶을 때

#### 내부 원리
파이썬 인터프리터는 함수 호출 시 다음 순서로 입력 인자를 처리함
1. 고정된 위치 인자들을 먼저 할당
2. 남은 위치 인자들을 모두 모아 하나의 튜플에 넣음
3. 그 튜플을 args라는 이름으로 함수 내부에 전달

즉, 메모리 구조 관점에서 보면 args라는 변수에는 불변(immutable) 튜플이 생성됨

### `**kwargs`의 동작 방식

함수에 전달된 키워드 인자들을 하나의 딕셔너리(dict)로 받아들임
```cpp
def func(**kwargs):
    print(kwargs)

func(a=1, b=2)
# 출력: {'a': 1, 'b': 2}
```

#### 내부 원리
인터프리터는 함수 호출 시 다음 단계로 처리함
1. 위치 인자와 키워드 인자를 구분
2. 키워드 인자들을 이름(key)과 값(value) 쌍의 딕셔너리로 묶음
3. 그 딕셔너리를 kwargs라는 이름으로 함수에 전달

즉, kwargs는 함수 안에서 일반적인 딕셔너리처럼 사용 가능함


## `*args`와 `**kwargs`의 중요한 특징
---
##### 순서가 매우 중요함
함수 정의 시 인자 순서는 아래와 같음
1. 일반 위치 인자
2. `*args`
3. 키워드 전용 인자
4. `**kwargs`

코드 예시:
```cpp
def func(a, b, *args, c=10, **kwargs):
    ...
```

**이 순서를 어기면 문법 에러가 발생하므로 유의**

##### 언패킹(Unpacking)을 지원함
- 리스트 또는 튜플 언패킹 -> * 사용
```cpp
nums = [1, 2, 3]
func(*nums) # nums 변수명 앞에 * 붙여 리스트 언패킹 사용
```
- 딕셔너리 언패킹 -> ** 사용
```cpp
config = {"lr": 0.001, "batch_size": 32}
func(**config) # config 변수명 앞에 ** 붙여 딕셔너리 언패킹 사용
```

## 유용하게 쓰이는 상황
---
##### 함수에 전달되는 인자의 개수를 유연하게 설계할 때
예: 로깅 함수, 수학 계산 함수, API 함수 등
```cpp
def add_all(*args):
    return sum(args)
```

##### 상속된 클래스에서 부모 클래스의 생성자 호출 시
예: 여러 개의 옵션을 유연하게 처리할 때
```cpp
class A:
    def __init__(self, **kwargs):
        self.config = kwargs

class B(A):
    def __init__(self, x, **kwargs):
        super().__init__(**kwargs)
        self.x = x
```

##### 데코레이터 작성 시
함수의 인자를 그대로 전달해야 하기 때문에 매우 자주 등장함
```cpp
def deco(func):
    def wrapper(*args, **kwargs):
        print("Before call")
        result = func(*args, **kwargs)
        print("After call")
        return result
    return wrapper
```

##### 특정 API나 라이브러리 함수가 인자를 직접 받지 않고 전달해야 할 때
예: [[Flask]], [[FastAPI]] 라우터 함수 내부
