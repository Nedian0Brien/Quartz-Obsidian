#강의노트 

어떤 논문을 읽는지가 중요 -> 나오는 논문을 모두 읽을 수는 없기 때문
어떤 논문으로부터 시작하는지가 중요!

1. 구글링으로 프로젝트 관련 논문 찾기
	(태스크명) + {awesome} + {github} + {paper history}
	ex) emotion in conversation + github
	태스크명은 이리저리 검색해봐야 함 + 업데이트가 실시간으로 되지 않은 문서일 수 있음
	> awesome 키워드를 입력하면 잘 정리된 문서를 찾을 수 있음

2. paperswithcode.com
	- 다양한 코드들과 데이터, 리더보드들이 존재
	- 태스크명을 정확히 몰라도, 적당히 키워드 등으로 매핑되는 것을 찾을 수 있음
	- 혹은 Datasets 등의 탭을 들어가서 수동으로 찾을 수도 있음

3. scholar.google.co.kr
	- 위 방식으로 원하는 논문 리스트들을 못 찾는 경우에 사용
	- 태스크와 관련된 최신 논문 하나를 찾고, 그 논문의 레퍼런스들을 추려서 자신만의 리스트를 만든다.

### 좋은 논문 찾기
1. 좋은 학회의 Publication
	- NLP 탑티어 : ACL / NAACL / EMNLP
	- AI 탑티어 : ICLR / NeurlPS / ICML
	- NLP 세컨티어 : COLING / EACL / AACL /  CoNLL
	- AI 어플리케이션 분야 : AAAI / IJCAI
	- Speech 분야 : INTERSPEECH / ICASSP
	- CV 분야 : CVPR / ECCV / ICCV

2. citation이 많이 되는 논문
	- 구글에 논문 제목 검색하면 인용지수 확인 가능
	- 많이 citation이 된 논문일수록 많이 알려져있고 검증이 되었다는 일종의 근거
	- 하지만, 최근 논문들은 비교적 citation이 적을 수 밖에 없음. citation이 많은 논문만 보면 최신 트렌드는 못 따라 갈 수도 있음

3. 성능이 좋은 것
	paperswithcode, 구글 검색 등을 통해 찾은 논문 리스트 중 성능 좋은 논문이 하나의 후보

> 결론 : 성능이 좋은 것 중 좋은 학회지에 publication이 된 것을 추천
