# 회귀분석 

#Statistics 

회귀분석을 할 때에는 [[다중공선성]]을 주의해야

=> [[다중공선성]]이 모델의 예측 성능을 떨어뜨리는 이유는 무엇인가?
다중공선성을 띄는, 그러니까 의미적 중복이 되는 피처들이 여럿 있으면 데이터 편향이 발생하고 해당 피처가 과대표현되기 때문인가?

### 회귀분석 유형 예
- 선형 회귀([[Linear Regression]])
- 로지스틱 회귀([[Logistic Regression]])
- 리지 회귀([[Ridge Regression]])
- 라쏘 회귀([[Lasso Regression]])
- 다항 회귀([[Polynomial Regression]])
