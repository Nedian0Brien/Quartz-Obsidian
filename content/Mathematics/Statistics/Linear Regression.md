# 선형회귀
: 종속 변수 Y와 1개 이상의 독립 변수 x와의 *선형* 상관 관계를 모델링하는 회귀분석 [[Regression Analysis]] 기법이다
-> 기존 데이터를 활용해 수치형(이산/연속) 변수 값을 예측

1. 단순선형회귀
2. 다중선형회귀

예측값에 대해 [[Cost Function]]을 사용해 오차를 계산한다

#### 선형 회귀분석 모델의 예측력 향상에 좋은 4가지 가정
1. 선형성 : 독립변수와 종속변수 간의 분포 관계가 *선형의 관계*를 가진다.
2. 독립성 : 독립성은 다중 회귀분석의 중요한 기본 가정으로 독립변수와 다른 독립변수 간의 *상관관계가 적을 경우* 선형 회귀 모델의 예측력이 좋아진다.
3. 등분산성 : 데이터의 [[Variance]]이 일정한 것. 데이터가 특정한 패턴 없이 *고르게 분포*하는 것이, 특정한 좁은 구간에만 집중해서 분포하는 것보다 더 나은 예측을 보인다.
4. 정규성 : 잔차([[residual]]) 혹은 오차([[error]])가 *정규성을 만족*해야 한다. 선형회귀에서 잔차 혹은 오차는 회귀직선과 관측값과의 차이를 의미한다.

## 선형회귀에서의 과대적합([[Overfitting]]) 해결책
1. 더 많은 데이터 활용하기 : 오류가 없고, 분포가 다양한 데이터를 많이 확보
2. 피쳐의 개수 줄이기 : 필요한 피쳐만 잘 찾아 사용
3. 적절한 매개변수 선정하기 : SGD의 학습률이나 루프의 횟수(epoch)처럼 적절한 하이퍼파라미터를 선정
4. 정규화([[Regularization]]) 적용하기 : 데이터 편향성에 따라 필요 이상으로 증가한 피쳐 가중치 값을 적절히 줄이는 규제 수식을 추가
