# 최소자승법

#Statistics 

[[Machine Learning]]에서 모델의 예측값과 실제값 사이의 [[Residual]]의 제곱의 합 또는 평균을 최소화하도록 파라미터를 결정하는 방법이다.

회귀 분석에서 모델 파라미터(예: 선형 회귀에서의 기울기와 y 절편)를 추정하기 위한 방법 중 하나

이때 [[Residual]] 의 값을 구하는 것이 [[Cost Function]]이다. 비용함수로 구한 잔차의 값을 제곱한 값을 최소화하는 것이 바로 최소자승법이다.

#### 왜 제곱하는가?
-> 잔차의 값이 음수일 수 있기 때문이다. 양수 잔차와 음수 잔차가 서로 상쇄되어 잔차의 절댓값을 제대로 반영하지 못할 수 있으므로 제곱하여 모두 양수 값으로 만든다.

#### 그렇다면 왜 절댓값을 사용하지 않고 제곱하는가?
-> 잔차를 제곱할 때 2차함수 식이 되고 기울기(Gradient)를 구할 수 있게 되므로 경사하강법(Gradient Descent)를 사용하여 잔차가 최솟값이 되는 지점을 찾아낼 수 있기 때문에?

>기계학습프로그래밍 강의 교안의 정의: 선형대수의 표기법을 사용하여 방정식으로 선형회귀 문제를 푸는 방법

### 최소자승법을 수행하는 과정
1. 비용함수를 미분한다.
2. 미분한 값을 0으로 만드는 최적의 가중치 값 w를 구한다.

MSE([[Mean Squared Error]])와의 차이:
- MSE는 모델 평가에 사용되는 지표 중 하나일 뿐이며, Least Square Method는 모델 파라미터를 추정하는 방법 중 하나이다.
- Least Square Method는 모델 파라미터를 찾는 알고리즘으로, 주어진 데이터와 모델 간의 잔차의 제곱을 최소화하기 위해 사용됩니다.
요약 : MSE로 얻는 값을 최소화하기 위해 사용하는 것이 Least Square Method
