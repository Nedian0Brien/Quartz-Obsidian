
베이지안 최적화(Bayesian Optimization)는 복잡하고 계산 비용이 높은 함수를 최적화하는 데 사용되는 전역 최적화 기법 중 하나입니다. 주로 머신러닝에서 [[하이퍼파라미터 튜닝]]이나 실험 설계 등에 활용됩니다.

베이지안 최적화의 주요 아이디어는 함수의 사후 분포를 추정하고, 이를 바탕으로 최적의 입력 값을 선택하는 것입니다. 이는 다음과 같은 과정을 통해 이루어집니다:

1. 대체 모델 (Surrogate Model) 구축:
   - 실제 최적화 대상 함수를 대신하여, 이를 근사하는 대체 모델을 구축합니다.
   - 대체 모델은 주로 가우시안 과정(Gaussian Process)이나 베이지안 신경망 등을 사용하여 구성됩니다.
   - 대체 모델은 함수의 평균과 불확실성을 추정할 수 있어야 합니다.

2. 획득 함수 (Acquisition Function) 정의:
   - 획득 함수는 입력 공간에서 어떤 점을 선택하는 것이 가장 유망한지를 평가하는 함수입니다.
   - 대표적인 획득 함수로는 Expected Improvement (EI), Upper Confidence Bound (UCB), Thompson Sampling 등이 있습니다.
   - 획득 함수는 대체 모델의 평균과 불확실성을 고려하여 탐색과 활용의 균형을 유지합니다.

3. 최적화 과정 반복:
   - 획득 함수를 최대화하는 입력 값을 선택하고, 그 점에서 실제 함수 값을 평가합니다.
   - 평가 결과를 바탕으로 대체 모델을 업데이트하고, 불확실성을 줄입니다.
   - 이 과정을 반복하면서 점진적으로 최적의 입력 값을 찾아갑니다.

베이지안 최적화는 다음과 같은 장점을 가지고 있습니다:
1. 효율성: 실제 함수를 직접 최적화하는 것보다 대체 모델을 사용하여 효율적으로 최적화를 수행할 수 있습니다.
2. 불확실성 고려: 대체 모델의 불확실성을 고려하여 탐색과 활용의 균형을 유지하므로, 전역 최적해를 찾을 가능성이 높습니다.
3. 저차원 및 고차원 문제에 적용 가능: 저차원부터 고차원까지 다양한 최적화 문제에 적용할 수 있습니다.

하이퍼파라미터 튜닝에서 베이지안 최적화를 활용하면, 적은 수의 평가만으로도 좋은 하이퍼파라미터 조합을 찾을 수 있습니다. 이는 그리드 서치나 랜덤 서치와 같은 전통적인 방법보다 효율적입니다.

베이지안 최적화는 머신러닝 외에도 로보틱스, 자율 주행, 재료 과학 등 다양한 분야에서 복잡한 시스템의 최적화에 활용되고 있습니다.
