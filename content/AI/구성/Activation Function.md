> 활성화 함수의 특징
- 비선형 함수
	**활성화 함수를 사용하는 이유**는 네트워크에 비선형성을 더하기 위해서이다.
	활성화 함수는 선형 함수가 아닌 비선형 함수여야 한다. 활성화 함수가 선형 함수이면 사용하는 의미가 없다.
		비선형 함수란 직선 1개로는 그릴 수 없는 함수를 말한다. 즉, f=wx+b와 같은 식으로 표현되지 않는 함수를 말한다.
	활성화 함수가 선형 함수라면 네트워크를 아무리 깊게 만들어도 결국 1개의 선형 함수로 환원될 수 있기 때문에 의미가 없다.
	때문에 일반적으로 인공신경망 네트워크의 활성화 함수는 비선형 함수를 사용한다.
	
	그러나 이것이 선형 함수 층을 사용하지 않는다는 의미는 아닌데, 종종 활성화 함수를 사용하지 않는 층을 인공신경망에 넣는 경우가 있다. 이러한 층을 '선형 층'(linear layer) 혹은 투사 층(projection layer)이라고 말한다.

	임베딩 층(embedding layer)도 일종의 선형층이다.
	
> 활성화 함수의 종류
1. Step Function(계단 함수)
	![[Pasted image 20230921185851.png]]
	거의 사용되지 않는는다. 퍼셉트론을 통해 인공신경망 개념을 처음 배울 때 접한다.
2.  Sigmoid Function
	![[Pasted image 20230921185934.png]]
	출력값을 0~1 사이의 범위로 변환하며 출력값이 0,1에 가까워지면 기울기가 완만해진다.
	이 구간에서는 미분값이 0에 가까운 아주 작은 값으로 변하는데, 역전파[[Backpropagation]] 과정에서 이 0에 가까운 값들이 누적해서 곱해지면서, 앞 부분 레이어에는 기울기(미분값)이 잘 전달되지 않게 되는 기울기 소실([[Vanishing Gradient]]) 문제가 발생한다.
3. Hyperbolic tangent Function (하이퍼볼릭 탄젠트 함수)
	
2. ReLU
3. Leaky ReLU
4. Softmax Function
