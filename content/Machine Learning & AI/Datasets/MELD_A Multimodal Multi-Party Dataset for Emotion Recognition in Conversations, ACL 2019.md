#논문
#### 용어 설명
- Multimodal : text, audio 기반의 데이터셋, 얼굴 사진은 align은 안되어있음(scene만 제공)
- Multi-Party : 다화자간의 대화(2명 이상)

#### 논문 요약
- 대화 속 감정인식에서 상당히 많이 쓰이는 데이터 세트 논문
- 기존에 EmotionLines라는 ERC 데이터 세트가 있었는데, 이를 잘못된 레이블을 필터링하고 멀티모달로 확장
- Friends 티비 프로그램에서 수집한 데이터 세트
- 다화자간 데이터이지만 필터링을 통해 두 명의 대화로 만든 버전도 존재
- 다중 annotation을 통해 레이블링. 다수결을 따라 레이블링하지만 다수결이 안되는 경우 해당 데이터는 삭제
- 감정 클래스 체계는 Ekman+neutral, 감성 클래스는 sentiment을 제공
	- Ekman이란?
		폴 박사가 인간의 기본 감정을 분류한 것(분노, 혐오, 두려움, 기쁨, 슬픔, 놀라움)
		다른 감정은 이들의 복잡한 조합으로 될 수 있다.
		ex) 창피함 = 두려움 + 분노
	즉 Ekman 6개 감정 + 중립을 더해 7개 클래스로 태깅

- 논문에서 bsLSTM과 dialogueRNN을 이용하여 실험함
- text + audio를 같이 결합하여 실험해봄 -> 성능 향상
	audio는 결합하여 사용할 때 어느 정도의 성능 향상이 있으나 text가 성능에 기여하는 바가 훨씬 큼
- context(이전 대화의 맥락)을 고려한 경우와 아닌 경우를 비교하면 context를 사용한 모델의 성능이 좋음
