# Machine Learning & AI

이 폴더는 머신러닝과 인공지능 관련 노트를 포함합니다.

## 하위 폴더 구조
- **Fundamentals/** - 기초 이론 (Gradient, Loss Function 등)
- **Models/** - 모델 구조 (CNN, GAN, Decision Tree 등)
- **Language Models/** - 언어 모델 (BERT, GPT, LLM 등)
- **Techniques/** - 기법 (Fine-tuning, PEFT, Embedding 등)
- **Neural Networks/** - 신경망 구조 (Transformer, LSTM, Attention 등)
- **Datasets/** - 데이터셋
- **Evaluation/** - 평가 지표
- **XAI/** - 설명가능 AI
