# 비용함수

손실함수(Loss Function이라고 하기도 함)

1. MSE([[Mean Squared Error]])
2. RMSE(Root Mean Squared Error)
3. MAE([[Mean Absolute Error]])
4. [[Binary Crossentropy]]
5. [[Categorical Crossentropy]]
6. Focal loss

### 비용함수의 편미분
- [[Partial Derivative]] 은 다변수 함수에서 관심이 있는 한 변수만 변수로 생각하고, 나머지 변수들은 상수로 취급한 뒤 미분하는 방법이다.
- [[Machine Learning]]에서 모든 변수의 편미분을 벡터로 정리한 것을 기울기([[Gradient]])라고 한다.
