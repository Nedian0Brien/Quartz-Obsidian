## Reinforcement Learning from Human Feedback
#AI #LM #강화학습

: 인간의 피드백을 통해 모델을 강화하는 학습 과정
- 인공지능 모델이 사용자의 요구와 기대에 부합하는 방식으로 행동하고 결정을 내리도록 답변을 개선하는 접근법
- Alignment tuning이라고도 불림. 사용자인 인간들의 가치에 답변을 잘 맞추어(align) 조정하는 것.

#### 사용하는 이유
- 언어모델은 서비스에 바로 사용하기에는 여러 문제가 있음; 사용자의 지시에 따르지 않거나, 없는 사실을 지어내는 환각([[Hallucination]]) 현상을 보이거나, 편향된 답변을 보이거나, 혐오 표현이 포함된 답변을 내는 경우도 있음.
- 이러한 문제들을 해결하거나 제어 가능하게 만들기 위해 RLHF 파인튜닝을 진행
- LLM에게 인간이 가진 가치들과 선호를 가르쳐서 조금 더 안전한 상태, 통제 가능한 상태로 만듬

### RLHF Fine-tuning의 진행 과정
1. Supervised Fine-Tuning(SFT)
	인간이 직접 만든 소량의 지도학습 데이터셋을 활용해 Pre-trained LM에게 원하는 특정 정책이나 행동 방침을 모델에게 가르침
2. Reward Model(Mimic Human Preference)
	1단계를 거친 모델이 생성한 답변들에 대해 인간이 직접 다양한 답변 후보들을 평가하여 어떤 답변이 더 우수한지에 대해 순위를 매기고 점수를 부여함. 이 데이터셋을 활용하여 인간의 선호도와 가치를 반영하는 Reward Model을 학습.
3. PPO(Proximal Policy Optimization)를 이용한 SFT 모델 강화학습
	SFT 모델이 Reward Model과 상호 작용하면서 강화학습을 진행. PPO는 이러한 학습 과정을 최적화하는 알고리즘이며, 결과적으로 1번의 SFT 모델이 더욱 사용자의 선호를 받는 답변들을 하도록 유도함.
