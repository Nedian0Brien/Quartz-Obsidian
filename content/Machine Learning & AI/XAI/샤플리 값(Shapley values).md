#게임이론

게임 이론에서 샤플리 값(Shapley values)은 여러 참가자들이 협력하여 얻은 총 이익을 각 참가자에게 공정하게 배분하는 방법입니다. 이 개념은 여러 참가자(혹은 변수, 특성)가 팀을 이루어 어떤 목표(예를 들어, 수익 극대화)를 달성할 때, 각 참가자의 기여도를 평가하는 데 사용됩니다.

샤플리 값은 다음과 같은 원칙에 기초합니다:

1. **공정성**: 모든 참가자는 자신의 기여도에 비례하여 보상을 받아야 합니다.
2. **효율성**: 모든 참가자에게 분배된 보상의 총합은 협력을 통해 얻은 총 이익과 동일해야 합니다.
3. **대칭성**: 만약 두 참가자가 어떤 협력에서 동일한 기여를 한다면, 그들은 동일한 보상을 받아야 합니다.
4. **더미 플레이어**: 기여하지 않은 참가자는 보상을 받지 않습니다.

이를 머신 러닝 모델에 적용할 때, '참가자'는 모델의 입력 변수(특성)가 되며, '이익'은 모델의 예측 결과(예를 들어, 예측된 값이나 결정)입니다. 샤플리 값은 각 입력 변수가 최종 예측 결과에 얼마나 중요한 역할을 하는지, 즉 각 변수의 기여도를 측정합니다. 이를 통해 모델이 내린 결정이나 예측의 근거를 이해할 수 있게 해주며, 복잡한 모델을 해석할 수 있는 강력한 도구가 됩니다.

간단히 말해서, 샤플리 값은 각 변수가 최종 결과에 미치는 영향력을 공정하게 평가하여, 모델의 작동 방식을 이해하는 데 도움을 줍니다.
